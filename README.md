# Kickbase - Beste Aufstellung

Ein interaktives Tool zur Berechnung der optimalen Kickbase-Aufstellung unter Berücksichtigung von Budget, Positionen und Formkurven.

## Funktionen
- **Budget-Check:** Berücksichtigt deinen aktuellen Kontostand.
- **Positions-Limits:** Hält sich an die Kickbase-Regeln (1 TW, 3-5 ABW, 2-6 MF, 1-4 ANG).
- **Form-Multiplikator:** Berechnet erwartete Punkte basierend auf dem Durchschnitt und deiner persönlichen Einschätzung (Viel Mehr, Mehr, Normal, etc.).
- **Optimierung:** Findet die punktstärkste 11er-Kombination, die ins Budget passt.

## Live-Demo
Du kannst das Tool direkt hier nutzen: [https://scientai.github.io/kickbase-aufstellung/](https://scientai.github.io/kickbase-aufstellung/)

## Benutzung
1. Trage deinen Kontostand ein.
2. Füge deine Spieler hinzu (Name, Position, Durchschnittspunkte, Marktwert).
3. Wähle die erwartete Form für den nächsten Spieltag.
4. Klicke auf "Beste Aufstellung berechnen".
